# TRABASE

Your home base for exploring Japan.

TRABASE is a travel-support information site for international visitors who want to stay in one place and explore more of Japan.

## MVP

- Choose a base city
- Discover nearby day trips
- Compare travel time and cost
- Save a simple itinerary

## Local preview

Open `index.html` in a browser. The first prototype is intentionally dependency-free so the content model and traveler experience can be tested quickly.
